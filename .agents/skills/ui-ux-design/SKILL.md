# POS UI/UX Design Skill

## Role

Act as a senior UI/UX designer specializing in business applications, retail POS systems, and administrative dashboards.

Create interfaces that are modern, professional, clear, consistent, and efficient.

## Design Principles

- Prioritize usability.
- Prioritize cashier speed.
- Maintain visual hierarchy.
- Avoid unnecessary decoration.
- Keep spacing consistent.
- Use a consistent design system.
- Minimize unnecessary clicks.
- Make common actions easy to access.
- Support keyboard and touchscreen operations.

## Layouts

### Vertical

- Sidebar navigation.
- Nested menus.
- Top navbar.
- Breadcrumbs.
- User menu.
- Collapsible sidebar.
- Responsive behavior.

### Horizontal

- Top navigation.
- Dropdown menus.
- Nested navigation.
- Secondary menu when required.
- Responsive mobile navigation.

Both layouts must use shared pages and features.

## Design System

Create centralized variables for:

- Colors.
- Typography.
- Spacing.
- Border radius.
- Shadows.
- Layout dimensions.
- Component states.

Support light and dark themes.

Avoid hardcoded colors throughout the application.

## POS Screen

Optimize for:

- Fast product search.
- Barcode entry.
- Product selection.
- Cart visibility.
- Quantity changes.
- Discount.
- Payment.
- Checkout.
- Receipt printing.

Cashiers should not need to navigate through unnecessary pages to complete a transaction.

## Khmer and English

Ensure:

- Khmer characters render correctly.
- Fonts support Khmer.
- Translation does not break layout.
- Buttons support long translated labels.
- Tables and navigation remain readable.
- Text alignment is consistent.

## UI Components

Use consistent:

- Buttons.
- Form controls.
- Cards.
- Tables.
- Modal dialogs.
- Dropdowns.
- Alerts.
- Toast notifications.
- Badges.
- Page headers.

## Responsive Behavior

Test:

- Desktop.
- Laptop.
- Tablet.
- Mobile.

Use responsive Bootstrap grids and appropriate breakpoints.

## Accessibility

- Proper contrast.
- Clear focus states.
- Keyboard navigation.
- Appropriate labels.
- Accessible buttons.
- Meaningful feedback.

## UI Review Checklist

Before completing a task:

- Is the interface visually consistent?
- Is the page easy to use?
- Are the important actions clear?
- Is the spacing consistent?
- Does it work on smaller screens?
- Does Khmer display correctly?
- Are loading and error states included?
- Are buttons actually functional?

Do not create decorative functionality that does not work.
