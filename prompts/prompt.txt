## Skill File Requirements

Each SKILL.md must:

1. Begin with valid YAML frontmatter.
2. Include a unique lowercase skill name.
3. Include a detailed, clear description.
4. Explain the skill's role.
5. Define its responsibilities.
6. Define technical standards.
7. Define its workflow.
8. Include quality requirements.
9. Include relevant checklists.
10. Explain when the skill should be used.

Descriptions must be clear enough for Antigravity to identify when a skill is relevant automatically.

Skills must be specialized and avoid unnecessary duplication.

Use progressive disclosure. Keep each skill focused. If supporting references are required, create a `references/` directory inside the relevant skill rather than making the SKILL.md unnecessarily large.
